Sobre o curso

A maioria dos cursos de web ensina a montar telas. Este parte de outro lugar: um sistema web nasce de um problema de negócio, e o profissional que entrega valor é quem sabe percorrer o caminho inteiro — entender o requisito, desenhar a interface, escrever o front-end, modelar o banco, expor uma API, publicar em um servidor e proteger os dados.

É esse percurso completo que a formação segue, na mesma ordem em que ele acontece no mercado. Você começa estudando o sistema e levantando requisitos, passa por layout, HTML, CSS e JavaScript, entra em SQL com MySQL e DBeaver, entende como front-end, back-end, APIs e microsserviços se encaixam, e termina em hospedagem, integração entre sistemas e segurança.

O que você vai aprender

  • Estudar um sistema e transformar necessidades em requisitos claros
  • Criar o layout e implementá-lo com HTML e CSS
  • Programar comportamento e interatividade com JavaScript
  • Modelar e consultar bancos de dados com SQL, MySQL e DBeaver
  • Entender a estrutura da web: front-end, back-end, APIs e microsserviços
  • Hospedar a aplicação e gerenciar o servidor
  • Integrar sistemas diferentes e aplicar segurança e validação de dados

Perguntas frequentes

O curso é front-end, back-end ou full stack?

Os dois lados. Ele cobre a interface (layout, HTML, CSS, JavaScript) e também o que está por trás dela: SQL com MySQL, estrutura de back-end, APIs, microsserviços, hospedagem, integração entre sistemas e segurança.

Preciso saber lógica de programação antes?

Ajuda bastante, mas não é obrigatório: a formação parte do zero. Se você nunca programou, fazer o curso de Lógica de Programação e Algoritmos primeiro deixa a curva bem mais suave.

Qual banco de dados é usado?

MySQL, com o DBeaver como cliente para escrever e executar as consultas. São ferramentas gratuitas e amplamente usadas no mercado brasileiro.

O curso ensina a colocar o site no ar?

Sim. Há um módulo dedicado a hospedagem e gerenciamento de servidor, além de integração entre sistemas e segurança — as etapas que normalmente ficam de fora dos cursos introdutórios.
