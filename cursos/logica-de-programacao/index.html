Sobre o curso

Lógica de programação é a base de qualquer linguagem. Antes de decorar a sintaxe de JavaScript, Python ou Java, é o raciocínio lógico que define se você consegue quebrar um problema em passos executáveis — e é exatamente esse raciocínio que este curso constrói, do zero, sem pressupor nenhuma experiência anterior.

O caminho é o mesmo que uso em sala de aula na graduação em Ciência da Computação: primeiro os conceitos e tipos de dados, depois os comandos básicos, então algoritmos sequenciais escritos em pseudocódigo no Visualg, e só então as estruturas que dão poder de verdade ao código — condicionais simples e de múltipla escolha, laços `enquanto`, `repita...até` e, por fim, modularização com passagem de parâmetros.

O que você vai aprender

  • Entender o que é lógica de programação e por que ela vem antes da linguagem
  • Trabalhar com tipos de dados, variáveis, atribuição, entrada e saída
  • Construir algoritmos sequenciais e escrevê-los em pseudocódigo no Visualg
  • Usar comandos condicionais simples e de múltipla escolha para tomar decisões no código
  • Dominar estruturas de repetição (`enquanto` e `repita...até`) e saber quando usar cada uma
  • Modularizar algoritmos e entender passagem de parâmetros entre módulos

Perguntas frequentes

Preciso saber programar para fazer este curso?

Não. O curso começa do absoluto zero, pelos conceitos de lógica e tipos de dados, e assume apenas a matemática do ensino médio. É justamente o ponto de partida recomendado para quem nunca escreveu uma linha de código.

Qual linguagem de programação é usada no curso?

O foco é o raciocínio, não a sintaxe de uma linguagem específica. Os algoritmos são escritos em pseudocódigo (Portugol) no Visualg, uma ferramenta gratuita feita para ensino. Com essa base, migrar para Python, JavaScript, Java ou C fica muito mais simples.

Preciso instalar algum programa?

Sim, o Visualg — um interpretador de pseudocódigo gratuito e leve, usado para escrever e executar os algoritmos das aulas passo a passo.

O que são estruturas de repetição e por que elas aparecem tanto no curso?

São os comandos que fazem um trecho de código rodar várias vezes, como `enquanto` e `repita...até`. Elas concentram a maior parte da dificuldade de quem está começando, então recebem módulos dedicados, com exercícios que comparam quando usar cada forma.

Depois deste curso, qual devo fazer?

Com a lógica em pé, o caminho natural é escolher uma aplicação: desenvolvimento web para construir sistemas, banco de dados para trabalhar com SQL, ou mineração de dados para partir para Python e análise. Todos estão listados na página de cursos.
