Sobre o curso

Escrever um SELECT é o começo. Administrar um banco de dados é outra profissão: envolve decidir arquitetura, controlar quem acessa o quê, garantir que exista backup testado, recuperar a base quando algo dá errado e descobrir por que aquela consulta que rodava em 200 ms agora leva 40 segundos.

Este curso percorre exatamente essa trilha, do básico ao avançado. Começa nos conceitos e funções de um SGBD e nas arquiteturas centralizadas e distribuídas, passa por dicionário de dados, gerenciamento de usuários, segurança e controle de acesso, backup e recuperação, refinamento e identificação de problemas de performance, e fecha com a parte analítica: álgebra relacional, consultas avançadas em SQL e processos de ETL.

O que você vai aprender

  • Entender os conceitos e as funções de um SGBD e suas arquiteturas
  • Consultar e usar o dicionário de dados
  • Gerenciar usuários, permissões, segurança e controle de acesso
  • Planejar e executar backup e recuperação de bancos de dados
  • Identificar problemas de performance e refinar o banco
  • Aplicar álgebra relacional e escrever consultas SQL avançadas
  • Montar processos de ETL (extração, transformação e carga)

Perguntas frequentes

O que faz um DBA e o curso prepara para isso?

Um DBA (administrador de banco de dados) cuida de arquitetura, usuários, segurança, backup, recuperação e performance da base. Esses são exatamente os módulos centrais do curso, que vai do básico ao avançado nessas frentes.

Preciso saber SQL antes de começar?

Não é obrigatório. O curso parte dos conceitos de SGBD e evolui até consultas avançadas e álgebra relacional. Quem já escreve SQL no dia a dia aproveita mais rápido a parte de performance e ETL.

Qual banco é usado nas aulas?

MySQL como base prática, mas os fundamentos — arquiteturas, dicionário de dados, controle de acesso, backup, tuning, álgebra relacional — se aplicam a qualquer SGBD relacional, incluindo PostgreSQL, SQL Server e Oracle.

O curso cobre ETL e análise de dados?

Sim. O módulo final trata de ETL (extração, transformação e carga), que é a ponte entre administração de banco e projetos de dados. Para seguir por esse caminho, o curso de Mineração de Dados é a continuação natural.

Serve para faculdade ou só para o mercado?

Serve para os dois. O conteúdo acompanha a ementa de disciplinas de banco de dados e administração de dados da graduação, com o recorte prático de quem administra bases em produção.
